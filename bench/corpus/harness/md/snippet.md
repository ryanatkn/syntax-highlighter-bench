# Getting started

Install the package, then import the **one** function it exports:

```bash
npm install example-app
```

## Usage

1. Create a _config_ file.
2. Call `start()` with it.

> Requires Node 20 or later.

| option | default |
| ------ | ------- |
| `port` | `5173`  |

See the [API reference](https://example.com/api) for more, or open an
issue if something is unclear.
